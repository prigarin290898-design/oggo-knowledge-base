Процесс: как правильно, что нельзя, риски
Общее для всех — черновик, синхронизирован с комплектом на 21.09
1. Заказ и производственное задание
ПроцессЗаказ идёт по статусам Новый → Подтверждён → далее. П/з на ГП создаётся строго после «Подтверждён» и на основании заказа. Задание проводится сразу; изменение — с зафиксированной причиной.
НельзяБрать заказ в работу раньше «Подтверждён» · создавать п/з не на основании заказа · оставлять п/з непроведённым · снимать проведение без причины · менять статус без документа.
РискРвётся связь между обещанным покупателю и реально произведённым. Уже было: закрытое задание с фактом производства откатили в момент разбора — факт выпуска исчез из истории.
2. Движение материалов
ПроцессЛюбая передача — через «Перемещение», собранное по расчёту в «Снабжении». Печать, подпись с обеих сторон, фото в чат «Документы» в день движения.
НельзяДвигать без перемещения в программе · без распечатанного документа · без фото в чат · собирать «от себя» · пропускать перемещение п/ф.
РискБез документа неизвестно, на чьей стороне недостача. Уже было: 63 позиции уехали на ХП без перемещения и пересчёта.
3. Цены и номенклатура
ПроцессКарточку создаёт только Михаил, сразу с ценой продажи (S 161₽, M/XL 180₽). Правки техкарт — только через согласованный запрос директору.
НельзяКарточка без цены · нулевая цена по покупной позиции · карточки не от Михаила · смена типа номенклатуры · правка без согласования.
РискНулевая цена в приёмке навсегда фиксирует себестоимость партии как ноль — ФИФО разносит её по всем следующим продажам. Уже найдено 29 таких документов.
4. Даты и сроки
ПроцессДокумент заводится в день события. Расхождение — максимум сутки. Больше — только «восстановительный документ» с пометкой.
НельзяЗадним числом больше суток без пометки · дата в будущем · движение по складу после инвентаризации до конца месяца.
РискБез честной даты теряется реальная последовательность событий при расследовании расхождения.
5. Приёмка
ПроцессПриёмка — на основании заказа поставщику. Количество сверяется по УПД поставщика и физическим пересчётом. Нет документов — приёмку создать можно, но количество строго по факту пересчёта; отсутствие документов — сигнал запросить их у Михаила.
НельзяПринимать количество не по факту пересчёта, когда документов нет · оставлять их отсутствие без запроса Михаилу.
РискБез документа и без честного пересчёта — нет основания для претензии поставщику, либо цифры подгоняются под ожидание.
6. Бумажное сопровождение — 5 стыков
ПроцессНа каждой передаче ответственности — две подписи от руки, затем фото подписанного документа в чат «Документы» в день движения.
НельзяПередавать без двух подписей · заменять фото PDF-версией без подписей.
РискБез подписи с обеих сторон спор превращается в «я передавал / мне не передавали» без возможности разрешить его фактами.
